# Generated site imagery

Generated with the built-in image_gen tool. JPEG files in public/images are the website assets; PNG masters are in output/imagegen. These are generated concept illustrations for the existing sample portfolio content, not photographs of completed client work.

Replace image keys in src/data.js for projects, articles and services; page Banner imageKey props select section banners. The home reel uses studio.jpg as its poster. Project galleries pair the campaign concept with planning and post-production imagery.
